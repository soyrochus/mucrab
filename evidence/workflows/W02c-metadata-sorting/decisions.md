# W02c investigation and decisions

The increment covers Size, modified Date and Extension alongside existing Name
sorting. Permissions, owner and group need their own provider/platform contract;
they are deferred. The next queued workflow is recursive copy.

CFR and javap recovered original FileComparator, table sorting/focus callers,
SortInfo/Column, local/proxy/cached/abstract file getters and StringUtils. The
oracle calls original comparator/model/table methods from the pinned JARs.
A ProxyFile subclass supplies literal synthetic metadata fields only. Real
fixtures use original getters and independent Rust enumeration. No original
comparison, sorting or selection method is overridden or recompiled.

Before Rust implementation, the first generated candidate mixed extreme signed
metadata into complete sort transitions. It stalled in the original quicksort.
The initial capture helper timed out after 180 seconds and lost partial process
streams; requests and an incomplete receipt remain at
`artifacts/runs/W02c-20261016T140701Z-904e6753`. The replacement streams stdout
and stderr to disk before waiting. A second 90-second run retained 18 complete
sequences and watchdog thread stacks at
`artifacts/runs/W02c-20261016T141045Z-4dd64cbc`.

A narrowed probe at `artifacts/runs/W02c-stall-probe` retains the old candidate,
request and exact descending DATE/folders-first event. A Long.MIN_VALUE wrapped
difference has the same negative sign in both directions. Descending reverses
both to positive; the original partition loop can endlessly swap. This is an
original limitation, discovered before any native metadata implementation.

The full-order generator was bounded to sizes -1/nonnegative i64 and dates
within ±(i64::MAX / 2) milliseconds. Extreme named arithmetic cases became
explicit pair-only sequences, with null order/selection. No comparison result
was normalized, skipped or discarded after a Rust disagreement. The revised
original-only run `20261016T141444Z-7c72ef61` completed before Rust, freezing
contract and seeds. Reserved cases were first executed after implementation.
The portable original-stall fixture and 20-second diagnostic preserve the
excluded transition and exit 2 with zero equivalence cases.

The native comparator uses wrapping signed subtraction even for standalone
extreme pair tests. Native enumeration supplies sortable metadata; the adapter
rejects unsafe full-order synthetic inputs. Directories-first stays outside
descending inversion; size treats directories as zero and -1 as MAX. Equal
primary values use existing name comparison, including direction and table
permutation behavior.

Extension comparison uses Java simple case behavior. Rust lowercase expansion
would differ on Turkish I, sharp S and supplementary characters. Our own JDK
probe observed 1,483 non-identity simple-fold mappings over Unicode scalars.
The manifest pins JDK 25.0.4.1 and the facts digest; regeneration refuses changed
data. The native table contains observed facts, not copied JDK code. No runtime
Java dependency is added. Chrono with std only supplies UTC display, not sorting.
Cargo.lock adds only chrono and preserves all previous dependency pins.

The original full-GUI probe observes actual table options, visible identities,
focus and marks through five stages. It calls original sortBy entry points and
the hidden menu doClick on the event thread, without transforming classes.
The first GUI attempt inherited WAYLAND_DISPLAY and Robot screen capture failed;
its raw log is retained. The new preparation helper removes that variable when
launching under isolated Xvfb. The successful run retains direct Swing renders.
Optional original OSGi/logging warnings do not establish unrelated component
health. OS event dispatch and asynchronous scheduling remain outside the claim.

The native driver replays mouse/keyboard inputs on an isolated display with
PATH=/nonexistent. Both panes retain marks/focus through independent metadata
sorts and explicit/hidden refreshes. Raw full-screen captures are retained; the
README preview removes only the unused black virtual-screen margin. UI dates
show UTC to make millisecond and pre-epoch values inspectable. Original localized
date formatting is not part of the metadata ordering contract.
